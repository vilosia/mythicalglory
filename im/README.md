### 大厅为什么长这样：策略投注是主角

平台要把**策略投注**当成最推荐的玩法来卖，所以大厅的主体就是它：

- **精选卡＝策略投注页那两张卡本身**，不是另画一套简版。Hector 08-06：「它们就是精选卡」。
- **两组卡、两个去处**（08-06 六稿）：
  | 大厅上的卡 | 用的组件 | 标 | 点进去到哪 |
  |---|---|---|---|
  | 进行中 | `.bd-ocard`（进行中那张，收起态） | 绿「进行中」 | `#mine=代号` → **执行动态**（实盘明细 · 指令栏 · 急停） |
  | 可套用的策略 | `.bd-card`（模板那张） | 蓝「可套用」 | `#plan=代号` → **该模板的试算详情**（L2 · 调参数 · 启用） |
  两组代号刻意不重复：进行中用 C0404R5/C0506R5，模板用 B0404R6/C0303R6/B0505R4 ——
  同一个代号在一屏上出现两次（一次实盘 +¥21.20、一次回测 赚 ¥128）最容易被读成互相矛盾。
- **两种卡的抬头排法统一**（08-06）：第一行一律 **代号 → 游戏 chip → 状态标**
  （模板卡 `B0404R6 PK10 可套用`／进行中卡 `C0404R5 SG飞艇 进行中`）。
  玩法方向（跟投／反投）挪到第二行、与 `¥10/注 · 倍投3× · 追5回` 同行 ——
  它和金额策略是同一类信息；模板卡本来也是把方向写在规则句里，不单独挂在代号旁。
- **卡是「跑」出来的，不是手抄的**：`gen-featured-cards.js` 用 node 把 `hall-plans.html`
  的 v15 引擎跑一遍（引擎种子固定，结果稳定），把渲染好的卡写进 `index.html`（大厅）的
  `<!-- RUNNING:START/END -->` 与 `<!-- TEMPLATE:START/END -->` 之间。改名单就重跑：
  `node gen-featured-cards.js . C0404R5,C0506R5 B0404R6,C0303R6,B0505R4`
  （参数二＝进行中的代号，参数三＝模板的代号）
  ⚠ 四个标记之间的内容**不要手改**，重跑会覆盖。
- 大厅版做了三处减法（结构/类名/数值一律没动）：整卡包成链接、去掉卡内 ⓘ 与术语
  虚线（大厅没带那套气泡脚本，留着就是点了没反应的假控件）、去掉策略页的选中钩子。
- **游戏排降到策略投注下面**：游戏是「自己下注」的次级入口，主角位让给策略投注。
  （若要换回游戏在上，把 `index.html`（大厅）里 GameStrip 那个 `<section>` 搬回英雄卡下面即可。）

### 策略详情两处版面（08-07）

- **汇总行吸顶、搬到矩阵上面**：「窗口 ＋ 合计 ＋ 投/中/爆」是读下面十条线之前就想知道的三件事，
  原来它 sticky 在底部，要先划过十条线才看见。内页抬头收掉后顶部腾出了空间，正好放它。
- **走势图加高到 84px**（原 46px）：对齐大路那一栏（实测 ~125px）时试过 124，太高；取中间。
- **「近 1 小时」的来源与去除**：原来切「大路」会把**窗口**改写成 `ROADMAX=60` 期，
  于是窗口下拉里冒出一个不在 今天/近三天/近七天 之列的「近 1 小时」——
  等于画法在替玩家改口径。现在 **ROADMAX 退役**：切画法不再动窗口。
  大路改成只画**最近 120 期**（`ROADVIEW`），窗口（行头统计＋脚条合计）仍按你选的那一档算。
  为什么不让大路画满窗口：实测今天 1440 期＝~15,000px / 4,320 颗珠，近七天＝**10.6 万 px /
  3 万颗珠 / 233ms**，没人滚得完。现在是 1,404px / 360 颗珠 / 5–24ms。
  ⚠ 这就等于保留了一处**「图只画一段、数字算整段」**——刻意的，两害相权：
  宁可图只画一段并在画法旁那枚 ⓘ 里写明，也不要画法悄悄改掉玩家选的窗口。
  下钻（点 ✕ 看那一梯）若目标期早于这 120 期，会 toast 说明而不是静默定位失败。
- **车道图改横滚，不再压缩**：窗口一长（近三天/近七天），原来把上万期挤进 330px，
  爆仓的 ✕ 连成一道红墙。现在图宽随窗口走（`W = 340 × 窗口/一天`，上限 8 天＝2720px），
  外面 `overflow-x:auto`，默认停在**最右**（最新那一端）。
  两处配套细节：① `curvePath` 加了点数参数，宽图按约 1px 一个点取样，线不会变折线；
  ② `svg` 带 `width` 属性让 1 单位＝1px —— 否则 `preserveAspectRatio="none"` 会把 ✕ 横向拉扁；
  ③ 停最右要 `setTimeout(…,0)`：renderL2 有时在视图还没显示时跑，那时 `scrollWidth=0`。

#### 一条踩过两次的坑：新类名先查平台有没有

`shared/styles.css` 是 250KB 的平台样式，短类名很容易撞：
- `.bd-off` —— v15 里是「已停」行与按钮禁用态，我拿它当「官方」金标，把整行刷成金底；
- `.rrow` —— 平台里是钱包申请行（`display:flex`），我拿它当开奖列表行，球号被挤到抬头右边溢出。

两次都是<看起来没关系的地方>坏掉。加新类名前先跑一遍：

```bash
grep -n '\.你的类名\b' shared/styles.css shared/trialrun.css shared/plancard.css
```

### 演示口径（讲给客户前先知道）

- **进行中的策略全在 SG飞艇上**（节拍条的期号/倒计时是 SG飞艇的 80 秒周期，

  （PK10 / 极速时时彩）和明细列表（三个游戏混排）。
- **同一代号 = 同一游戏**：C0506R5 在全部策略和进行中都是 SG飞艇。
  大厅两张官方模拟卡（C0303R6 / B0505R4）在「全部策略」里也找得到（带金色「官方」标），
  大厅上的数字与页内今日回测同源（赚 ¥103 / 亏 ¥56，引擎种子固定所以每次打开都一样）。
- **进行中的每注是 ¥10 / ¥5**（08-06 改，原来四张全是 ¥1）：C0404R5 与 B0405R4 走 ¥10，
  C0506R5 与 C0405R12 走 ¥5。累计盈亏、倍投梯（10→30→90→270）、总投入、明细页那几条
  注单、大厅英雄卡的「今日投注 ¥125 / 今日盈亏 +¥37.10」全部按这个口径一起改过 ——

- **可套用的策略仍按每注 ¥1 回测**（卡片区顶上那条口径条写着）—— 回测是「同一把尺子量所有策略」，

## 5. 已知偏离与限制

- `hall-plans.html` 保留 v15 的密集数据字号豁免（8.5–11.5px 的微型标签），
  与 `Ref/Latest` README §6 同一条口径。`shared/plancard.css` 是这套卡样式的**原样副本**
  （给大厅用），所以同一条豁免也带了过去（17 处 9.5–11.5px）。颜色仍然全部走 token。
- **`:has()` 依赖**：内页隐藏导航用的是 CSS `:has()`（Safari 15.4+ / Chrome 105+）。
  更老的浏览器上导航不会隐藏 —— 只是多一条导航，不影响可用。
- **策略卡有两份样式**：`hall-plans.html` 内联那份是<权威>（那份稿刻意自包含，
  单开就能看），`shared/plancard.css` 是给大厅的副本 —— 改卡片外观时两边一起改，
  否则大厅与策略投注页会长得不一样。
- 明细页是静态样例（页签切换是演示 JS）；行内数据与 v15 的策略、
  游戏页的注单在**故事上**对齐，但没有共用数据源。
- 启用/急停/指令等流程与 v15 一致：到确认/提示为止，不真的落单。
- 未决事项（倍投归零、样本窗口等）沿用 `Ref/Latest` README §7，未在本版做决定。
