## 0. 这一版改了什么（2026-08-11 · Alex 会议 · R1 批次）

这一轮 Alex 改的是**骨架**，不是细节。会议逐字稿拆成 A–H 八组、四个批次，
**这一版只做了 R1**（结构 ＋ 进行中总览）。R2/R3/R4 还没动，清单在第 0.5 节。

### 0.1 结构：大厅拿掉，策略当落地页

> 「我主推我想要玩家一进来第一眼是看到这一个（策略），不要是这一个（手动投注）」
> 「手动 normal 投注营业额可能 10% 而已」
> 「去 Iris chat 那边就不用大厅了，你直接拿掉那个大厅，直接放这一个做那个入口」

| 改动 | 之前 | 现在 |
|---|---|---|
| 底部导航 | 大厅 / 策略 / 开奖 / 明细 | **策略 / 动态 / 彩票 / 开奖 / 明细** |
| 落地页 | `index.html`（游戏大厅） | **`hall-plans.html`（策略）** |
| `index.html` | 游戏大厅本体 | **一张转发页**，双击进去直接落策略 |
| 游戏大厅 | `index.html` | **`hall-lottery.html`**，页名改叫「**彩票**」 |
| 聊天 → 游戏厅 | 落大厅 | **落策略**（`pagenav.js` 的 `'hall'` 改指 `hall-plans.html`） |
| 游戏屏返回键 | 回大厅 | 回**彩票**（新路由 `'lottery'`）—— 那几屏是从彩票点进去的 |
| 旧大厅 `hall.html` | 导航第一格 | **退役**，文件留着对照，导航上没有它了 |

- 为什么留一张转发页而不把策略页搬成 `index.html`：`hall-plans.html` 是 546KB 的 v15 引擎整版，
  改文件名要动它自己四十多处相对引用与 pagenav 的六条旧路由，换来的只是文件名好看。
  而 Hector 与客户都是双击 `index.html` 开原型的 —— 转发页让这个习惯不用改。
- 转发用 `location.replace`（不是 `href`），不留历史记录，否则策略页按返回会弹回转发页。
- **顺序**：策略排第一格（它也是落地页），动态紧跟着 —— 分享出去的策略就落在动态里，
  两格挨着才是一条动线；手动投注的彩票退到中间。
- **动态的图标用喇叭筒（公告），不是音箱**：第一版画的是「音箱＋两道声波」，
  与「开奖」那三颗球一样是圆弧堆叠，缩到 24px 后两格看着像同一类东西；
  喇叭筒有握把这个独有的轮廓，一眼分得开，也更贴「公告」这个词。
- 七个页面的 `nav` 是同一段结构，用脚本一次换掉的，不是手改七遍。

⚠ `shared/reference-theme.css` 里四条 `a.nav[href="index.html"]` 的游戏厅 webp 图标规则
**现在不再命中任何元素** —— 它们在 08-08 那段「一套 24px 描线图标」里早就被
`display:none/content:none` 关掉了，本来就是死规则。这一轮没去动它（要清就两段一起清）。

### 0.2 新页：动态（`hall-activity.html`）

> 「不是群聊啦，就是大家不能讲话，但是还是一个群」「就是一个公告这样子的东西」
> 「反正就是有一个地方让我一直做 broadcasting 的东西就好了」

只读广播频道，两类内容：**策略分享卡**（主角）＋ **系统播报**（窄条配角）。
分享卡上那几个数是 Alex 指定的：代号 · 游戏 · 方向 · **玩法定位（冠军·大小）** ·
**执行线路几条** · **今日爆仓几次** · **距上次爆仓多少期** · **快照时间**。

- 官方/专家账号用**金线外框 ＋ 角标**，卡内结构与普通卡一字不差
  （Alex：「内容是一样的，只是那个 frame 不一样」）；配一颗「不看 TA」。
- 分享出去的是**冻结快照**，卡上写明「分享后不再更新」—— Tex 说 live update 做不到
  （「100 个人分享…那个 cost 很高而且容易断线」）。
- ⚠ 本页数据是**形态样本**，与 `hall-plans` 的引擎**还没接线**；接线是 R3 的事。
  `cardBustStats()` 已经在算「今日爆仓 / 距上次爆仓」，R3 直接取，别另写一套。

⚠ **一个撞名要 Alex 拍板**：策略页里 `.view-feed` 已经叫「**执行动态**」（一条策略的实盘明细），
现在底部导航第三格也叫「动态」。同一个 App 两个动态，玩家会以为是同一样东西。
备选：这一页改叫 广场 / 播报 / 频道，或把内页那个改叫「实盘」。
**这一版先按 Alex 说的字面用「动态」**，没自作主张。

### 0.3 进行中总览：三格 → 三条计划线

> 「总盈亏现在是三个 Plan 嘛…可以给它切出来 Plan B、Plan C」
> 「如果今天我是有三行，我就可以知道三个里面，眼睛里面看我就知道是哪一个开哪个关」
> 「我有一个 critical 的去到 Round 5 了，我很紧张的，但是我在这边没有注意到 —— 你上面没有跟我讲」

`我的策略` 顶部原来是 **总盈亏 ｜ 策略进行中 3/3 ｜ 本期投入** 三格，现在换成
**一条策略一行**：`● 代号 · 这期掏多少几注 · 累计盈亏 · 打到第几回`。

- **「策略进行中 3/3」删掉** —— Alex：「这个信息可有可无，因为我最多只有三个而已」。
- **「本期投入」从一个总数拆到每一行** —— 一个总数看不出是哪个策略要掏钱。
  总盈亏留在抬头右边：它是这一屏唯一真的该合起来看的数。
- **在跑的永远置顶**；急停/未启用的**收成一行**（`已急停 1 · 未启用 1 ▾`），点开才摊。
  为什么不全摊：Alex 同一场会里还有一句抱怨是「我就算全部收起，也只能看到两个（卡）」——
  五行全摊开会把卡片再往下推约 150px，等于用一个抱怨换另一个。
- **回合预警**：打到全程 **2/3** 转琥珀、**最后一回**转红并加 `!`。
  2/3 是照 Alex 举的例子定的 —— 12 回合的计划「到 Round 8 就开始有一个特别的 symbol」，
  `ceil(12×0.66)=8` 正好落在他说的那一回。
- **整行可点** → 直接进那条策略的执行动态（与卡片同一个去处，不另造第二条路）。
- 停掉的那几行连**盈亏的红绿也一起退灰**：那笔钱已经不动了，还刷成红色会跟在跑的抢注意力。

⚠ 这一块**没有第二份数据**：投入/注数走 `thisPeriod()`、回合取各线 `chase/stuck` 里最深那一条、
盈亏就是 `m.pl`，全部由 `renderPlanRows()` 现算。改口径只改那一个函数。

### 策略详情两处版面（08-07）

- **汇总行吸顶、搬到矩阵上面**：「窗口 ＋ 合计 ＋ 投/中/爆」是读下面十条线之前就想知道的三件事，
  原来它 sticky 在底部，要先划过十条线才看见。内页抬头收掉后顶部腾出了空间，正好放它。
- **走势图加高到 84px**（原 46px）：对齐大路那一栏（实测 ~125px）时试过 124，太高；取中间。
- **「近 1 小时」的来源与去除**：原来切「大路」会把**窗口**改写成 `ROADMAX=60` 期，
  于是窗口下拉里冒出一个不在 今天/近三天/近七天 之列的「近 1 小时」——
  等于画法在替玩家改口径。现在 **ROADMAX 退役**：切画法不再动窗口。
  大路改成只画**最近 120 期**（`ROADVIEW`），窗口（行头统计＋脚条合计）仍按你选的那一档算。
  为什么不让大路画满窗口：实测今天 1440 期＝~15,000px / 4,320 颗珠，近七天＝**10.6 万 px /
  3 万颗珠 / 233ms**，没人滚得完。现在是 1,404px / 360 颗珠 / 5–24ms。
  ⚠ 这就等于保留了一处**「图只画一段、数字算整段」**——刻意的，两害相权：
  宁可图只画一段并在画法旁那枚 ⓘ 里写明，也不要画法悄悄改掉玩家选的窗口。
  下钻（点 ✕ 看那一梯）若目标期早于这 120 期，会 toast 说明而不是静默定位失败。
- **车道图改横滚，不再压缩**：窗口一长（近三天/近七天），原来把上万期挤进 330px，
  爆仓的 ✕ 连成一道红墙。现在图宽随窗口走（`W = 340 × 窗口/一天`，上限 8 天＝2720px），
  外面 `overflow-x:auto`，默认停在**最右**（最新那一端）。
  两处配套细节：① `curvePath` 加了点数参数，宽图按约 1px 一个点取样，线不会变折线；
  ② `svg` 带 `width` 属性让 1 单位＝1px —— 否则 `preserveAspectRatio="none"` 会把 ✕ 横向拉扁；
  ③ 停最右要 `setTimeout(…,0)`：renderL2 有时在视图还没显示时跑，那时 `scrollWidth=0`。

#### 一条踩过两次的坑：新类名先查平台有没有

`shared/styles.css` 是 250KB 的平台样式，短类名很容易撞：
- `.bd-off` —— v15 里是「已停」行与按钮禁用态，我拿它当「官方」金标，把整行刷成金底；
- `.rrow` —— 平台里是钱包申请行（`display:flex`），我拿它当开奖列表行，球号被挤到抬头右边溢出。

两次都是<看起来没关系的地方>坏掉。加新类名前先跑一遍：

```bash
grep -n '\.你的类名\b' shared/styles.css shared/trialrun.css shared/plancard.css
```
