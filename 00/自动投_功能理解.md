## 1. 产品定位

自动投 = 让系统按玩家预设规则自动下注的策略工具。三大卖点：**全天监控、即时执行、实时报告**。
解决的痛点：追长龙不用手点、不盯盘也不漏一期、实时追踪随时急停。

一个策略的生命周期：**扫描触发 → 固定执行 → 独立风控截停 →（持续监测 / 只执行一次）**。

```
    ├── 急停二次确认（bottom drawer）/ 删除二次确认（居中 popup）
    └── 首次引导 drawer（3 页，每会话弹一次）
```

### 2.1 策略卡与下方区域的状态规则（2026-07-15 client 确认，已实装）

- 卡片区不再显示额外的「策略」标题和问号。每张卡的 Header 左侧为小字「官方模板 / 自定义策略」＋策略名，右侧为跨两行高度的状态图标；运行中使用呼吸 Play 图标。选中蓝卡只表示当前查看，运行状态与选中状态相互独立。
- 卡片的标题区与数据区以弱分隔线区分。运行/急停卡纵向展示「累计盈亏 / 累计投入」，未运行官方模板纵向展示「均盈利 / 人用过」；每个数字独占完整卡宽，不做左右双列。
- 卡片底部保持紧凑，不为累计投入留下大段空白；运行状态使用雷达扫描动效表达持续监测。执行动态 Header 的急停按钮与相邻图标按钮等高，展开注单的表格 Header 使用可读性更高的字号和字重。
- 教程结束后固定显示三张策略 Tab：官方「小本试水」、官方「反投策略」、「新增策略」；永远只有一张 Active。**Active = 当前查看对象，不代表已启用。**
- 未启用的官方模板下方显示只读策略设置；无执行 Feed、无指令栏；屏幕底部固定「编辑 / 启用」双 CTA，避免玩家读到底部后回滚寻找启动入口。
- 「新增策略」在未创建时只是入口卡，点击即开分步创建 Drawer；此时不渲染空内容区或指令栏。
- 策略启用后，下方切换为执行动态 Feed：先追加本期触发与自动投注信息，开奖后再追加命中与盈亏结果；Header 提供分享、设置、急停，底部显示指令栏。
- 急停后保留 Feed 与指令栏，Header 动作为「重新启用」。玩家可以继续通过指令修改 Active 策略，修改只在重新启用后生效；已提交注单继续等待开奖并写入结算动态。
- 指令栏只在策略至少启用过一次后开放：运行中、已急停、已完成均可用；官方模板预览、尚未启用的自定义策略及未创建的新增占位不可用。
- 执行动态 Header 只保留一个「筛选」入口，Bottom Drawer 内按「动态类型 / 时间」分组；开奖结果可再筛盈利或亏损，同期投注执行作为结果上下文一起保留。
- Feed Header 固定为「时间｜期号＋执行事实｜右侧金额」：已投行右侧投注金额用绿色；结算行标题明确写「已结算＋命中数」，右侧单期盈亏按盈利绿、亏损红、持平灰；未投行右侧留空。
- Feed 视觉层级：Feed Header 始终白底；展开详情为极浅灰，Table Header 再深一级。未达到条件整行中灰弱化；策略启用用蓝色 `▶`＋深色正文，策略创建用中灰正文，历史事件右侧不重复当前状态。
- 累计投入与累计盈亏只在对应策略卡显示一次，不在 Feed 上方另设「本次运行」摘要，也不在每期 Feed 重复。每期展开详情仍保留本期投入、预计盈利、命中和计划进度等非累计 Summary；急停详情保留未中注数与计划进度，并只处理急停当期，历史期留在下方 Feed。

## 2.5 PK10 玩法基础（2026-07-10 由需求方提供并确认）

开奖 ＝ 10 台车（1–10 号）排出 冠军～第十名，每名次对应一个车号，**车号不重复**。

| 玩法 | 判定规则 | 投注项数 |
|---|---|---|
| 1–10 两面盘 · 大小 | 该名次车号 ≥6 ＝【大】，≤5 ＝【小】 | 10 |
| 1–10 两面盘 · 单双 | 车号单数 ＝【单】，双数 ＝【双】 | 10 |
| 1–5 龙虎 | 冠军vs第十、亚军vs第九、三vs八、四vs七、五vs六；前者车号大 ＝【龙】，小 ＝【虎】（车号不重复，必出龙或虎） | 5 |
| 大龙大虎 | **第一至第五名车号总和 大于 第六至第十名总和 ＝【大龙】，小于 ＝【大虎】**（总和 55，必分胜负、无和局） | 1 |
| 冠亚和 单双 / 大小 | 冠军＋亚军车号之和（3–19）：单/双；>11 ＝【大】，≤11 ＝【小】 | 各 1（**不纳入玩法选择**，2026-07-10 定案：曾短暂加入后移除） |
| 车号指定（冠军～第十名） | 押某名次开出某车号 | 定位模式基础（热号/冷号） |
| 冠亚和 指定 | 押和值具体数字 3–19 | 非两面形态，不在自动投范围 |

- 自动投「两面」扫描四类（大小 10 ＋ 单双 10 ＋ 龙虎 5 ＋ 大龙大虎 1 ＝ 最多 26 项）；「定位」对应车号指定。
- 注意：冠亚和大小/单双的和值分布不对称（非 50/50），长龙/单跳统计特性与名次两面不同；若将来纳入扫描需单独说明。

## 3. 核心业务逻辑

### 3.1 扫描与触发（长龙区间 S）
- 系统持续扫描 PK10 全部 10 个名次的大小 / 单双 ＋ 5 组龙虎对位；**每个投注项独立判断、独立触发、互不影响**。
- 「最低等于长龙数量」＝入场门槛：连开达到该值才触发（例：冠军大 4 期 ✓、第 6 名单 2 期 ✗）。
- 「最高等于长龙数量」＝入场上限：连开已超过（如 ≥9）不再追，防追过热。
- 区间只是**开闸条件**，仅在入场那一刻判断一次。

### 3.2 两面逻辑（2026-07-10 最终口径：跟投数长龙、反投数单跳）
- **跟投＝长龙形态**：同方向连开（大大大…）达到区间后触发，顺方向继续投——连开大 3 期：第 4 期投【大】。
- **反投＝单跳形态，没有长龙**：方向交替（大、小、大…）达到区间后触发，投上一期的反向——大、小、大：第 4 期投【小】。需求案例二并非笔误。
- **两者共用「最低 / 最高」区间参数**（如 3–8 期），区别只在计数的形态（长龙 vs 单跳）；UI 话术随执行方向切换（长龙数量 / 单跳数量）。
- 旧称「跟龙 / 反龙 / 追龙 / 砍龙」已全部废弃，所有界面统一为 跟投 / 反投。

### 3.3 执行阶段（下注回合数 M）
- 触发后**雷打不动执行满 M 期**：长龙中断、中途输赢都不提前停；唯一例外是止盈 / 止损截停。
- 多个投注项同时触发时**并行**，各自跑各自的 M 期。
- **执行中再触发（已确认）**：执行途中同一目标又形成新长龙时，**可以叠加一条并行执行，但需玩家确认后才生效**（弹确认，玩家同意才叠加）。

### 3.4 金额策略
- **固定投**：每期同额（5,5,5,5,5）。
- **倍投**：按「倍投倍数」**逐回合递增**（×2 → 5,10,20,40,80）；**中奖也不重置，继续递增**（已确认，非传统马丁格尔）；最后「尾数回合数量」期改用较低的「尾数倍投倍数」接续递增，压住尾段指数级资金消耗。

### 3.5 止盈止损（全部投注项合计 · 2026-07-10 更新口径）
- **全部被触发的投注项合并累计盈亏**：合计盈利达到止盈、或合计亏损达到止损，**整套策略立即停止**。
- ~~旧口径「单项独立、各自截停」已废弃~~（早期需求图为单项口径，后经确认改为合计）。

### 3.6 风险口径
- 总投入上限 ＝ 单注 × 回合累计（倍投为递增序列求和）× 理论可并发投注项上限（大小 10 ＋ 单双 10 ＋ 龙虎 5 ＋ 大龙大虎 1）。
- 最坏投入 ＝ min(总投入上限, 止损额度)。**金额影响最多投入，但会被止损封顶**。
- 爆仓数据：基于历史开奖回测倍投最深需追到第几回；**仅适用倍投 / 长龙，定位模式不显示入口**。
- **货币口径**：本游戏不用真钱，全程不出现「¥」，金额一律以「**额度**」表述。

### 3.7 定位模式
- 按名次当日热号 / 冷号执行，不走长龙扫描；触发规则与两面不同。

### 3.8 时间与风控
- 暂停 / 恢复投注时间；「恢复后是否继续回合」（继续＝承接进度 / 重置＝从第 1 回合）。
- 「完成后继续监测」（持续监测 / 只执行一次）。
- **以上两项可跳过不选**，默认按 继续 / 持续监测 执行。

## 4. 新建策略 · 5 步向导规范

步骤：**玩法设置 → 触发条件 → 执行方式 → 风控设置 → 确认策略**

- 标题统一「新建策略 · 步骤名」，步骤名灰色弱化；步骤下不放说明行。
- **选项默认为空**（玩法模式、玩法选择、执行方向、资金方式、风控两项）；数值类保留合理默认（金额 10、回合 10、长龙 3-8、止盈 1000 / 止损 500）。
- 分步校验：玩法模式 → 玩法（两面至少 1 项）→ 执行方向 → 资金方式必选；风控两项可跳过。
- 选项内不放小字注解；各组 label 旁 **"?" 点击后在选项下方展开**逐条说明，再点收起。
- 玩法选择：方形 chips、不带（10）（5）计数。
- 「当前策略」摘要条（第 1–4 步常驻）：策略摘要 ＋ **预估共 N 个投注项**；「**最多投入 X 额度**」从第 3 步（执行方式，设置额度后）才出现，并附计算说明（单注 × 回合 × 投注项数，与止损额度取较小者），输入时实时刷新。
- 执行方式内容全部展开：倍投参数（倍投倍数 / 尾数回合数量 / 尾数倍投倍数）常驻显示，标注「选倍投时生效」。
- 定位模式下隐藏爆仓数据入口。
- Sheet 高度 92%、隐藏滚动条（仍可滚）；确认页 ＝ 规则汇总 ＋ 风险预估（低 / 中 / 高，只看投入不预测收益）。
- 官方模板（小本试水 / 长龙反投）＝ **极速启用**：点卡直接弹「启动确认」（玩法 / 每期投入 / 最坏情况 / 达到止盈 / 占用预算，预算透明），确认即启动；「调整设置」才进 5 步向导（参数预填）。

## 5. 策略中心（L1）规范

- **最多 3 个策略**；三列卡片并排完整显示，不裁切；满员后新建入口收起，任何入口再触发都提示上限。
- 卡片摘要统一紧凑格式：`两面/跟投/3-8/单注10/10回合/固定`（定位：`定位/热3冷2/…`）。
- 卡片内含 **修改 ＋ 急停**（非运行中为 启动 / 重启）；**运行中可直接修改**，不必先急停。
- 卡片盈亏显示：`+¥120` / `−¥40` / 监测中 / 已停止 / 待启动。
- **执行动态跟随选中卡**（默认最新建立的策略）；点卡切换，选中卡蓝框高亮，feed 标题带策略名。
- feed **首条展开**为详情：设置行（摘要＋止盈止损）→ 每个投注项目（名称 / 第几回合 / 预估金额 / 达单项止损的标「已暂停」置灰）→ **本期结算 · 合计盈亏**（＝各项明细之和）→ 查看完整报告入口。
- 其余各期折叠单行，文案按策略真实参数生成（未达长龙 ≥N / 按「跟投」执行 / 长龙已超 N 期不再入场）。

## 6. 首次引导 drawer

- 每会话首次进入自动投弹一次；高度 380px；无顶部拖拽把手；pagination 圆点在主按钮上方（每页各一组）。
- 三页：让系统帮你盯盘看走势（无三图标）→ 你的策略设置 → 结果一目了然。
- 配套图标（已重绘 SVG，存于 自动投_引导图标/）：全天监控（眼＋循环箭头）、即时执行（秒表＋闪电）、实时报告（报告＋脉冲＋信号点）；风格＝深靛蓝 #2E3ECC → 天蓝 #55A8F2 对角渐变描边、20px 圆角笔触。

## 7. 全局 UI 规范（本次确立）

- **讯息 toast**：白色圆角卡片（20px 圆角、深色加粗文字、柔和投影），**画面正中**显示，自动消失；覆盖 #gToast 与 .dashtoast 两套。
- 启动确认弹窗做预算透明：玩法 / 每期投入 / 最坏情况 / 达到止盈 / 占用预算 ＋ 预算退回说明。
- 急停随时可用、二次确认、未用预算立即退回余额。

## 8. 已确认口径

| 事项 | 结论 |
|---|---|
| 结算 | ＝该期所有投注项目的合计盈亏 |
| 金额与最多投入 | 金额影响最多投入，被单项止损封顶（口径与确认页一致） |
| 执行动态默认 | 跟随最新建立的策略 |
| 风控两项 | 可跳过，默认 继续 / 持续监测 |
| 命名 | 全局统一 跟投 / 反投 |

## 9. 原开放问题 · 已全部确认（2026-07-10）

1. **反投定义（最终版，覆盖此前记录）**：案例二**并非笔误**——反投触发按**单跳（方向交替）**计数，不是长龙：大、小、大（3 期单跳）→ 第 4 期投上一期的反向【小】；跟投才按长龙（同方向连开）计数。两者共用最低 / 最高区间参数。
2. **执行中再触发**：**可以叠加并行，但需玩家确认**后才生效。
3. **倍投中奖后**：**继续递增，不重置**。
4. **止盈止损话术**：实际规则是按投注项**从触发起累计**（累计亏 500 / 累计盈 1000 即停该项）；UI 文案统一用「单项止盈 / 单项止损（按投注项累计）」，避免「每期每注」被误读为单期限额。原型已按此话术实现。
